## Controle Metodológico  
* Não use teologia sistemática para resolver o debate.  
* Não descarte posições sem avaliação.  
* Diferencie dados exegéticos e pressupostos.  
* Reconheça ambiguidades legítimas.  
* Não dedique peso desproporcional a debates classificados como periféricos — precisão filológica não é sinônimo de importância para o sentido.  
O objetivo é identificar qual interpretação explica melhor os dados textuais disponíveis.
